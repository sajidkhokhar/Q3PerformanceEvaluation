01 High API cost in MenuSmart ▾
Action
  • Investigated root cause of unexpectedly high API usage
  • Updated all app APIs and moved sensitive calls to Cloud Functions
  • Integrated Cloud Function calls separately for better control and security
  • Built an in-app real-time API cost monitor to track usage live within the app
  • Strengthened project architecture and security practices across the board
⚠ Cons
  • Had to absorb the initial unexpected API cost
  • Required time to investigate, refactor, and redeploy
✦ Pros & Impact
  • Created a reusable in-app API cost monitor — first of its kind in the team
  • Raised team-wide awareness of real-time API cost tracking
  • Bandan implemented the same real-time API cost module for DietPlan
  • Ameya created the same module for Captions
  • Turned a costly mistake into an engineering standard adopted by multiple developers
  • Better API cost visibility now exists across 3 projects
  • Improved architecture, security practices, and project structure for all future projects
